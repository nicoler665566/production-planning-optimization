# Multi-Period Production Planning

Model production decisions across three products, two plants and five planning periods.

## Technical approach

Formulate a mathematical optimization problem incorporating demand, selling prices, advertising, raw materials and labor costs.

## Technologies

PuLP, pandas, matplotlib

## Project materials

- `NU Industry Project v2.ipynb`

## Getting started

Open the original notebook and install PuLP and the other imported packages.

For notebooks, use a compatible Python/Jupyter environment and install the imported libraries. Original environment-specific paths may need local adjustment.
